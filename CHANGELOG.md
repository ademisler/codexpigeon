# Changelog

## 0.1.0

- Electron desktop shell for repo-local Codex mailbox workflows.
- CLI for doctor, install, send, watch, snapshot, and automation commands.
- Plain Markdown mailbox protocol with strict app/agent file ownership.
- Read-only Codex App Server discovery and method allowlisting.
- Project-local hook runtime and managed installer templates.
- macOS local development installer for CLI and desktop launchers.
